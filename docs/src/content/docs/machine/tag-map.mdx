## Usage

```sh
machine-memory tag-map list
machine-memory tag-map set cli/src area:cli,topic:commands
machine-memory tag-map suggest cli/src/cli/app.ts
machine-memory tag-map delete cli/src
```

`tag-map` is filesystem-only and does not take `--local` or `--remote`. It
stores mappings in `.agents/path-tags.json` relative to the current working
directory.

| Action                              | Behavior                                                                                             |
| ----------------------------------- | ---------------------------------------------------------------------------------------------------- |
| `list`                              | Print the file path and all configured mappings.                                                     |
| `set <path_prefix> <tag1,tag2,...>` | Normalize and save a mapping.                                                                        |
| `suggest <path\|path,path,...>`     | Return the tags for one or several paths, with `matches` (path, prefix, tags) and `unmatched` paths. |
| `delete <path_prefix>`              | Remove a mapping and report whether it existed.                                                      |

Mappings are consumed by `add --path`, which reports the same matches as
`path_tag_matches` and warns on stderr about a path that matches no prefix.
