## Usage

```sh
machine-memory stats (--local|--remote)
```

`stats` returns the total memory count, breakdowns by memory type and
certainty, tag frequency, the oldest memory, memories not updated for more
than 90 days, and memories without tags. It includes all statuses and returns
JSON without output-mode flags.
