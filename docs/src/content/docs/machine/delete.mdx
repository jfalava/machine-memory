## Usage

```sh
machine-memory delete <id> (--local|--remote)
machine-memory delete <id,id,...> (--local|--remote)
```

`delete` removes the specified memory rows permanently. It is intentionally
ID-based and does not support matching or a dry-run mode. Use `deprecate` when
the historical record should remain available.
