## Usage

```sh
machine-memory get <id> (--local|--remote)
machine-memory get <id,id,...> (--local|--remote)
```

`get` retrieves exact memory IDs for the current repository. A single ID
returns one object; multiple IDs return a `results` array and report any
missing IDs separately. It does not take output-mode flags.
