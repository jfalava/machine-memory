## Usage

```sh
machine-memory diff <id> <new_content> (--local|--remote)
```

`diff` returns whether the proposed content conflicts with the stored content,
its similarity score, the terms added, and the terms removed. It is a
read-only comparison; use `update` to persist the proposed content.
