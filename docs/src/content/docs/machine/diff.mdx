## Usage

```sh
machine-memory diff <id> <new_content> (--local|--remote)
```

`diff` returns whether the proposed content conflicts with the stored content,
its similarity score, the terms added, and the terms removed. It is a
read-only comparison; use `update` to persist the proposed content.

`dropped` lists what the proposal would lose. `identifiers` are paths, flags,
versions, and similar tokens from the stored content that the proposal no
longer contains, spelled as stored. `sentences` are stored sentences that
keep fewer than half of their terms. An update replaces the whole content, so
carry each one over or confirm it is obsolete:

```json
{"id": 42, "conflict": false, "similarity": 0.4,
 "dropped": {"identifiers": ["src/ui/Keycap.tsx"],
             "sentences": ["Keycap styling lives in src/ui/Keycap.tsx."]}}
```
