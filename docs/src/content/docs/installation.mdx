---
title: Installation
description: Download and install the standalone machine-memory CLI binary.
---

## Download

Download the binary for your platform from the [latest GitHub release](https://github.com/jfalava/machine-memory/releases/latest):

| Platform            | Release asset                     |
| ------------------- | --------------------------------- |
| macOS Apple Silicon | `machine-memory-darwin-arm64.zip` |
| Linux x64           | `machine-memory-linux-x64.zip`    |
| Linux arm64         | `machine-memory-linux-arm64.zip`  |
| Windows x64         | `machine-memory-windows-x64.zip`  |

## Install

Extract the release archive for your platform. Put the executable inside anywhere on your `PATH`.

> For UNIX users, you may need to make it executable:

```sh
chmod +x machine-memory
```
