These commands change local configuration, provision infrastructure, or update the instructions that agents read from `AGENTS.md`. They are intentionally interactive or operational rather than database-query primitives.

## Before you begin

Run the CLI from the repository you want to configure. `init` requires exactly one backend flag:

```sh
machine-memory init (--local|--remote)
```

The remote backend stores its Worker URL and token in the operating system keychain. The repository documentation uses `--remote`; use `--local` only when you explicitly want a SQLite database for another project.

> `--remote` requires the userspace to have access to the OS keychain. This is guaranteed on Windows and macOS machines, but Linux users must have a compatible `libsecret` keychain available on the shell session.

## Commands

| Command                                       | Purpose                                                                       |
| --------------------------------------------- | ----------------------------------------------------------------------------- |
| [`init`](/human/init)                         | Create or replace the managed memory block in `AGENTS.md`.                    |
| [`remote setup`](/human/remote-setup)         | Save credentials for an existing authenticated Worker.                        |
| [`remote provision`](/human/remote-provision) | Deploy a new Alchemy D1 stack and save its credentials.                       |
| [`upgrade`](/human/upgrade)                   | Download and replace the installed CLI binary from the latest GitHub release. |
