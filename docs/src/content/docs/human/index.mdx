These commands change local configuration, provision infrastructure, or update
the instructions that agents read from `AGENTS.md`. They are intentionally
interactive or operational rather than database-query primitives.

## Before you begin

Run the CLI from the repository you want to configure. `update-agents-md`
requires exactly one backend flag:

```sh
machine-memory update-agents-md --remote
```

The remote backend stores its Worker URL and token in the operating system
keychain. The repository documentation uses `--remote`; use `--local` only
when you explicitly want a SQLite database for another project.

## Commands

| Command | Purpose |
| --- | --- |
| [`update-agents-md`](/human/update-agents-md) | Create or replace the managed memory block in `AGENTS.md`. |
| [`remote setup`](/human/remote-setup) | Save credentials for an existing authenticated Worker. |
| [`remote provision`](/human/remote-provision) | Deploy a new Alchemy D1 stack and save its credentials. |
