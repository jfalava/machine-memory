Remote commands manage the authenticated Cloudflare D1 Worker backend.

| Command                                       | Purpose                                  |
| --------------------------------------------- | ---------------------------------------- |
| [`remote setup`](/human/remote/setup)         | Save credentials for an existing Worker. |
| [`remote provision`](/human/remote/provision) | Deploy a new D1-backed Worker stack.     |
